*astro-ru.txt* Русское практическое руководство по AstroNvim

==============================================================================
ASTRONVIM: БЫСТРЫЙ СТАРТ                                      *astro-ru*

Это руководство описывает AstroNvim v6 и локальные настройки данного
репозитория. Основы редактирования вынесены в |vim-ru|.

Содержание:

1. Первые действия...............................|astro-ru-start|
2. Как находить комбинации.......................|astro-ru-discovery|
3. Файлы и поиск.................................|astro-ru-files|
4. Буферы и окна.................................|astro-ru-buffers|
5. Работа с кодом и LSP..........................|astro-ru-lsp|
6. Git, терминал и плагины.......................|astro-ru-tools|
7. План обучения.................................|astro-ru-practice|
8. Диагностика mappings..........................|astro-ru-mappings|

==============================================================================
1. ПЕРВЫЕ ДЕЙСТВИЯ                                      *astro-ru-start*

В этой конфигурации:

  <Leader>       пробел
  <LocalLeader>  запятая

Нажмите пробел и немного подождите. which-key покажет доступные группы и
описания команд. Не пытайтесь сразу запомнить всё меню.

Минимальный набор на каждый день:

  <Leader>e      открыть или закрыть дерево файлов
  <Leader>ff     найти файл
  <Leader>fw     найти текст в проекте
  <Leader>fb     выбрать открытый буфер
  <Leader>fk     найти mapping
  <Leader>fh     найти раздел справки
  <Leader>c      закрыть текущий буфер

Команды вводятся последовательно, а не одновременно. Для `<Leader>ff`
нажмите пробел, затем `f`, затем ещё один `f`.

==============================================================================
2. КАК НАХОДИТЬ КОМБИНАЦИИ                          *astro-ru-discovery*

Есть три основных способа:

1. Нажать `<Leader>` и читать меню which-key.
2. Выполнить `<Leader>fk` и искать по названию действия или клавишам.
3. Использовать команды `:map`:

>
  :nmap
  :verbose nmap gd
  :verbose nmap <Space>ff
  :verbose xmap d
<

`:verbose` показывает действие и файл, который создал mapping. Это полезнее
статического списка: плагины могут добавлять локальные комбинации только
после открытия нужного типа файла.

Для поиска обычной команды Vim используйте:

>
  :help слово
  :help motion
  :help text-objects
<

Русские разделы этого руководства можно искать через `<Leader>fh`, указав
часть тега, например `astro-ru-lsp`.

==============================================================================
3. ФАЙЛЫ И ПОИСК                                        *astro-ru-files*

  <Leader>e      переключить Neo-tree
  <Leader>o      перейти в Neo-tree
  <Leader>ff     найти файл
  <Leader>fF     найти файл, включая скрытые
  <Leader>fw     поиск текста по проекту
  <Leader>fW     поиск текста, включая скрытые файлы
  <Leader>fc     найти слово под курсором
  <Leader>fo     открыть недавний файл
  <Leader>fC     найти и выполнить команду

Практический сценарий:

  1. `<Leader>ff` открывает нужный файл.
  2. `<Leader>fw` находит использование имени во всём проекте.
  3. `<Leader>fb` возвращает к уже открытому файлу.

Neo-tree скрывает имена, начинающиеся с точки. Для разового поиска скрытого
файла удобнее использовать `<Leader>fF`.

==============================================================================
4. БУФЕРЫ И ОКНА                                      *astro-ru-buffers*

Буфер — открытый файл, окно — область экрана, показывающая буфер.

  Shift-L        следующий буфер
  Shift-H        предыдущий буфер
  <Leader>fb     выбрать буфер через поиск
  <Leader>c      закрыть текущий буфер
  CTRL-h         перейти в окно слева
  CTRL-j         перейти в окно снизу
  CTRL-k         перейти в окно сверху
  CTRL-l         перейти в окно справа
  CTRL-Up        увеличить окно вверх
  CTRL-Down      увеличить окно вниз

Не закрывайте Neovim только ради смены файла. Откройте несколько файлов и
переключайтесь между их буферами.

==============================================================================
5. РАБОТА С КОДОМ И LSP                                 *astro-ru-lsp*

Эти mappings доступны, когда для текущего буфера запущен language server:

  gd             перейти к определению
  gD             перейти к объявлению
  gy             перейти к определению типа
  gI             перейти к реализации
  gr             найти ссылки на символ (локальная настройка)
  K              показать документацию символа
  <Leader>la     выбрать code action
  <Leader>lr     переименовать символ
  <Leader>lf     отформатировать документ
  <Leader>ls     найти символ документа
  <Leader>lG     найти символ рабочего пространства
  [d             предыдущая диагностика
  ]d             следующая диагностика
  <Leader>ld     показать диагностику строки

Если `gd` или `gr` ничего не делает, сначала проверьте LSP:

>
  :checkhealth vim.lsp
  :verbose nmap gd
<

Проверяйте mappings именно в исходном файле проекта: LSP-команды часто
являются buffer-local.

==============================================================================
6. GIT, ТЕРМИНАЛ И ПЛАГИНЫ                             *astro-ru-tools*

  <Leader>gt     показать Git status
  <Leader>gc     найти commits репозитория
  <Leader>gC     найти commits текущего файла
  <Leader>gb     выбрать ветку
  <Leader>tl     открыть Lazygit
  <Leader>tf     открыть плавающий терминал
  <Leader>th     открыть горизонтальный терминал
  <Leader>tv     открыть вертикальный терминал
  <Leader>ps     показать состояние плагинов
  <Leader>pu     проверить обновления плагинов
  <Leader>pm     открыть Mason

Для просмотра изменений в отдельном интерфейсе доступна команда:

>
  :DiffviewOpen
<

Не запускайте обновление плагинов во время изучения mappings без причины:
после обновления поведение и доступные команды могут измениться.

==============================================================================
7. ПЛАН ОБУЧЕНИЯ                                    *astro-ru-practice*

День 1: `<Leader>ff`, `<Leader>fw`, `<Leader>fb`, `<Leader>e`.
День 2: движения и операторы из |vim-ru-motion| и |vim-ru-operators|.
День 3: `gd`, `gr`, `K`, `[d`, `]d`.
День 4: буферы и окна из |astro-ru-buffers|.
День 5: Git и терминал только для реальной рабочей задачи.

Добавляйте не более пяти новых комбинаций за раз. Если действие выполнено
через меню или мышь дважды, найдите его через `<Leader>fk` и в третий раз
используйте клавиатуру.

==============================================================================
8. ДИАГНОСТИКА MAPPINGS                              *astro-ru-mappings*

Локальные mappings находятся в:

  lua/plugins/astrocore.lua   общие команды
  lua/plugins/astrolsp.lua    команды LSP

Режимы в таблице mappings:

  n   normal
  x   visual
  o   ожидание движения после оператора
  i   insert
  t   terminal

После изменения конфигурации перезапустите Neovim. Для проверки конкретной
клавиши используйте `:verbose {mode}map`, например:

>
  :verbose nmap D
  :verbose omap D
<

См. также |vim-ru-local| для нестандартных `d`, `D`, `U` и `CTRL-R`.
